# Ajmal Electronics - AI Support Chatbot

An AI-powered customer support chatbot built with FastAPI and Google's Gemini API. 
The bot answers questions about Ajmal Electronics products, which are sold through 
Pittappillil Agencies showrooms across Kerala, and can find the user's nearest 
showroom using real browser geolocation.

**Live demo:** https://ai-customer-support-chatbot-lvbr.onrender.com

## Features
- Conversational AI chat grounded in company-specific product and store information
- Remembers conversation context across multiple messages
- "Find Nearest Store" button using browser geolocation and distance calculation
- Clean, responsive chat UI (plain HTML/CSS/JS, no framework)

## Tech Stack
- **Backend:** Python, FastAPI
- **AI:** Google Gemini API (google-genai SDK)
- **Frontend:** HTML, CSS, JavaScript (no framework)
